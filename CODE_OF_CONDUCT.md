# Code of conduct

Vitamux follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). In short: be respectful and constructive, assume good intent, and do not harass anyone.

Report unacceptable behaviour privately to the maintainers through a GitHub security advisory or a direct message to a maintainer. Reports are handled confidentially. Maintainers may remove content or contributors that violate this code.
