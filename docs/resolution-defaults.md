# Built-in resolution defaults

Generated by `go run ./internal/resolve/gen` from [`internal/resolve/builtin.go`](../internal/resolve/builtin.go); do not edit. The reasoning, evidence and review policy are in [architecture/resolution-defaults.md](architecture/resolution-defaults.md); the rule language is in [resolution.md](architecture/resolution.md#rule-specification).

A built-in applies while the owner has no rule for the metric. The first edit copies it into the owner's version 1, and from then on it is an ordinary rule. Groups are tried in ladder order (`first_available`, `event_priority`); an input joins the first group it matches. Groups naming a connector that does not exist yet stay empty, and the ladder starts at the next group.

## Coverage

- `metric: sleep` covers every `sleep_derived` code; `metric: blood_pressure` covers the `bp_reading` components.
- No built-in for `skin_temperature`: the value depends on where the device is worn, so there is no neutral order; the owner picks one source.
- Codes not in [metrics.md](metrics.md) get their built-in together with the code.
