# J02.1 Migration tooling and roles

Epic: [E02 Database foundation and migrations](README.md) · Status: done (2026-10-03) · Depends on: J01.2
Read: [reliability#upgrades](../../architecture/reliability.md#upgrades), [security#database-roles](../../architecture/security.md#database-roles)

**Objective:** Safe, repeatable schema changes.

## Outputs
- `internal/db/migrations`, `vitamux migrate up|status` (`down-to` in dev builds only)
- `deploy/sql/roles.sql` (`vitamux_owner`, `vitamux_app`)
- Startup schema-version check

## Done when
- Two concurrent `migrate up` runs: exactly one applies, both exit 0.
- `serve` exits non-zero on an older or newer schema.
- `vitamux_app` cannot `CREATE TABLE` (test).
