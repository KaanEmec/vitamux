# J23.4 Chart kit on LayerChart

Epic: [E23 Charts and metric visualisation redesign](README.md) · Status: done · Depends on: J23.2, J23.3
Read: [frontend#chart-grammar](../../architecture/frontend.md#chart-grammar), ADR-0022 (from J23.2)

**Objective:** Rebuild `lib/charts/` on LayerChart while keeping the components' public API, so pages change little.

## Outputs
- `TimeSeries`, `Bars`, `RangeDumbbell`, `Sparkline`, `Hypnogram`, `EventLanes` and `CoverageStrip` rebuilt on LayerChart, with the same props.
- New: `StageStack`, `RangeBars` (bedtime and wake), `Histogram`, `BrushNavigator`, and source overlays on `TimeSeries`. The nightly stage stacks are `Bars` with one stack per stage; `StageStack` is one night as one bar.
- `ChartTooltip` as a crosshair card: value, status marker, source, and Explain, Override and Raw records.
- Animated transitions on data change (off under reduced motion); touch scrub.
- `ChartFrame` keeps one tab stop, the arrow keys, the table fallback and the `vx-chart-render` measure.
- `chartFor` and the grammar are unchanged.

## Done when
- Each component has a Playwright spec on fake data covering both themes, keyboard focus and the table fallback.
- A 14,400-point day renders in under 500 ms, and the chunk stays within the J23.2 budget.
