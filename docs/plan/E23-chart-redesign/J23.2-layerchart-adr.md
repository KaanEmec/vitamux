# J23.2 LayerChart ADR (supersedes ADR-0020)

Epic: [E23 Charts and metric visualisation redesign](README.md) · Status: todo · Depends on: None
Read: [ADR-0020](../../adr/0020-chart-kit.md), [frontend#technology](../../architecture/frontend.md#technology)

**Objective:** Record the move to LayerChart with measured numbers and a new budget.

## Outputs
- A spike that builds the HRV detail chart (line, band, overlays, crosshair, brush) on LayerChart and measures:
  - the lazy chunk size (gzip);
  - render time at 14,400 and 50,000 points, with the existing min/max-per-column decimation from `scale.ts` applied first;
  - CSP `style-src 'self'` violations (must be 0);
  - the keyboard model from `ChartFrame` working on top.
- ADR-0022 (superseding ADR-0020), and the [ADR index](../../adr/README.md) and [frontend#technology](../../architecture/frontend.md#technology) updated with the new chart-chunk budget.

## Done when
- The ADR is accepted with measured numbers.
- The chart chunk budget is set in `scripts/bundle-budget.mjs`, or the rule is written there if it applies only to lazy chunks.
