# J23.11 Controls and overall UX pass

Epic: [E23 Charts and metric visualisation redesign](README.md) · Status: todo · Depends on: J23.3
Read: [frontend#design-system](../../architecture/frontend.md#design-system)

**Objective:** Make every control as polished as the charts, so the whole panel feels like one product.

## Outputs
- Primitives in `lib/ui/` and `base.css` restyled to the v3 language:
  - buttons (primary, secondary, ghost, danger, icon);
  - text fields;
  - select (native, custom chevron);
  - checkbox, radio and switch (toggle);
  - segmented control and tabs;
  - chips;
  - dialogs and drawers;
  - popovers and tooltips;
  - empty states, skeletons, toasts and alerts.
- Consistent focus rings, hover and pressed states, disabled states, 44 px touch targets and reduced motion.
- A sweep of Connections (including setup), Rules (including the builder), Lab, Settings and login. Each page moves onto the primitives and loses page-local control styles. Layouts and behaviour stay as they are.

## Done when
- No page styles its own controls.
- axe passes in both themes at 1280 px and 390 px.
- The e2e suite passes.
