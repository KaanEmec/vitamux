# J23.6 Dashboard redesign

Epic: [E23 Charts and metric visualisation redesign](README.md) · Status: done · Depends on: J23.4, J23.5
Read: [frontend#navigation](../../architecture/frontend.md#navigation), [J21.7](../E21-visualisation/J21.7-dashboard.md)

**Objective:** A dashboard where stat tiles drive one large chart, as on the canvas.

## Outputs
- Hero stat tiles (default: steps, resting HR, HRV, weight; set by `hero` in the layout). Each shows the latest value, the period mean and a sparkline. The selected tile drives the hero chart.
- The hero chart: a period switch (7D, 30D, 90D, 1Y with weekly means), the grammar's view, a mean line, a range and a neutral delta, source chips, and a link to Explore.
- A last-night card: hypnogram, stage composition, bed and wake times, and the source.
- Pinned cards with a value, sparkline, neutral delta and source chip. Edit mode (pin, reorder, size, hide) still works.
- The alert strip restyled. Layout works at 390 px with horizontally scrolling tiles.

## Done when
- The Playwright specs cover tile selection, period switching, the tooltip, edit mode and 390 px.
- The page loads in under 1 s on the synthetic 3-year dataset.
