# J23.7 Metric detail and Explore

Epic: [E23 Charts and metric visualisation redesign](README.md) · Status: done · Depends on: J23.4, J23.5
Read: [J21.8](../E21-visualisation/J21.8-explore.md), [J21.10](../E21-visualisation/J21.10-rule-lens.md)

**Objective:** The canvas's metric detail for every metric, from the grammar.

## Outputs
- A stats header: latest, period mean with delta, range, and coverage.
- The main chart with:
  - source overlay toggles;
  - fallback and override markers;
  - shaded no-data gaps;
  - a source-per-window strip;
  - a brush navigator;
  - a "Compare previous" overlay.
- A distribution (histogram with the mean) and the values table: status, source and rule version.
- The rule lens restyled as the side panel: a plain sentence, drag-to-reorder sources with window counts, strategy and window, a draft-vs-active mini chart with the change summary, and the history with revert.
- Explore rows with the metric tile, a sparkline, the latest value and source chips.

## Done when
- The Playwright specs cover overlays, the tooltip actions, brush zoom, the lens draft and save, and 390 px.
