# J08.3 Measures stream and normalizer

Epic: [E08 Withings official connector](README.md) · Status: todo · Depends on: J08.2, J06.6, J07.4
Read: [metric-catalog](../../architecture/metric-catalog.md), [data-model#tables](../../architecture/data-model.md#tables), [resolution#group-coherent-selection](../../architecture/resolution.md#group-coherent-selection)

**Objective:** Fetch and normalize measure groups.

## Outputs
- Descriptor `withings.measures` (hourly poll, rate limits); Plan (lastupdate, backfill chunks); Fetch with paging
- Normalizer: meastype → catalogue code per the `W` column of metric-catalog (`v1` rows); BP → `bp_reading`, weigh-ins → `body_composition`, other measures as plain samples; `value×10^unit`, manual flag, devices; goldens

## Done when
- Synthetic-year backfill then incremental has no gaps or duplicates.
- Goldens cover BP, weigh-in, manual entry, changed group, unknown meastype.
