# J08.2 OAuth connection flow

Epic: [E08 Withings official connector](README.md) · Status: done (2026-10-03) · Depends on: J08.1, J06.4, J03.2
Read: [overview#routes](../../architecture/overview.md#routes), [security#threat-model](../../architecture/security.md#threat-model)

**Objective:** Connect, reconnect and disconnect securely.

## Outputs
- `Authenticator` implementation
- `/oauth/withings/callback` (GET exchange, HEAD → 200)
- Signed, single-use, session-bound `state`
- `account_key` from the Withings user id; encrypted credentials; reauth; disconnect

## Done when
- HEAD → 204 with no side effects.
- Replayed or foreign `state` is rejected.
- Reconnecting reuses `account_key` (no duplicates).
