# J08.4 Notifications (optional per install)

Epic: [E08 Withings official connector](README.md) · Status: done (2026-10-03) · Depends on: J08.3
Read: [overview#routes](../../architecture/overview.md#routes), [security#threat-model](../../architecture/security.md#threat-model)

**Objective:** Lower latency without requiring webhooks.

## Outputs
- Subscribe/list/revoke
- `/webhooks/withings/{hook_token}` (HEAD/GET → 200; POST → deduplicated window sync)
- Settings toggle; polling stays on

## Done when
- Wrong hook token → 404, no job.
- 10 notifications for one window → 1 job.
- Turning off revokes the subscriptions.
