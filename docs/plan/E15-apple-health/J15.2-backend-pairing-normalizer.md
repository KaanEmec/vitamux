# J15.2 Backend pairing and HealthKit normalizer

Epic: [E15 Apple Health Bridge (required, v0.2.0)](README.md) · Status: done · Depends on: J15.1, J05.4, J07.4
Read: [apple-health#pairing-and-security](../../architecture/apple-health.md#pairing-and-security), [apple-health#payload](../../architecture/apple-health.md#payload), [apple-health#origins-and-relays](../../architecture/apple-health.md#origins-and-relays)

**Objective:** Server support without iOS coupling in the core.

## Outputs
- Pairing codes, `POST /devices/pair`, token rotate and revoke, `GET /devices/self`
- `healthkit.samples` normalizer (quantities mapped by the HK column of [metric-catalog](../../architecture/metric-catalog.md), sleep → sessions and stages, BP correlation → group, workouts; an unmapped type → warning, raw kept), adds the `E15` catalogue codes, deletions → tombstones, origins/devices/relay flags, `HKDevice` → `device_type` (incl. `chest_strap`, `arm_band`), anchor diagnostics; goldens

## Done when
- Goldens cover each type class, a deletion, relayed and native origins, a user-entered sample.
- Replayed batch is a no-op; a revoked token gets 401 immediately.
