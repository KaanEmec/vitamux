# J03.1 Master key and vault (ADR-011)

Epic: [E03 Security foundation: secrets, auth, tokens](README.md) · Status: in progress · Depends on: J02.3
Read: [security#keys-and-secrets](../../architecture/security.md#keys-and-secrets)

**Objective:** Encrypt credentials and document keys with a key held outside the DB.

## Outputs
- `vitamux admin init-secrets`
- `internal/crypto`: key loader with permission check, HKDF purposes, AES-256-GCM seal/open with AAD and `key_id`
- `vitamux keys rotate` (resumable)
- ADR-011

## Done when
- Tampering with ciphertext, nonce or AAD fails.
- Rotation re-encrypts all rows and is resumable.
- `/readyz` fails without a key.
