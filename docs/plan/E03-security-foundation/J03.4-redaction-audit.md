# J03.4 Redaction, safe HTTP client, audit helper

Epic: [E03 Security foundation: secrets, auth, tokens](README.md) · Status: todo · Depends on: J01.2, J02.2
Read: [reliability#health-logs-metrics](../../architecture/reliability.md#health-logs-metrics), [security#threat-model](../../architecture/security.md#threat-model)

**Objective:** Secrets and health payloads never reach logs, and sensitive actions are audited.

## Outputs
- Redacting `slog` handler
- `internal/httpx` client: timeouts, UA, header scrubbing, no body logging, response size cap
- `audit.Record()` with redacted diffs

## Done when
- Sentinel secrets in headers, queries and errors never appear in captured logs.
- Key and password operations write audit rows without secrets.
