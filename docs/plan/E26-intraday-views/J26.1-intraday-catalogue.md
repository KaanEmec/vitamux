# J26.1 Intraday metadata in the catalogue

Epic: [E26 Intraday views on the server and the panel](README.md) · Status: todo · Depends on: None
Read: [J22.26](../E22-ios-app/J22.26-intraday-views.md), [metric-catalog#rules](../../architecture/metric-catalog.md#rules)

**Objective:** Each metric records its default and finest intraday bucket, so every client draws the same thing without per-metric code.

## Outputs
- `Intraday{Default, Finest}` on `catalog.Metric`, set by aggregation per the J22.26 table with the E26 adjustments; `GET /metrics` and the generated `docs/metrics.md` expose it.
- Grammar fixture cases for each class and for a metric without `intraday`.

## Done when
- Catalogue tests check that every intensive and additive code has `intraday` and that daily-summary, latest and nightly codes have none; generators show no drift.
