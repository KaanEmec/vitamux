# J07.4 Canonical writer (ADR-016)

Epic: [E07 Normalization framework and provenance](README.md) · Status: done (2026-10-03) · Depends on: J07.3, J07.2
Read: [data-model#identifiers-and-dedupe-keys](../../architecture/data-model.md#identifiers-and-dedupe-keys), [data-model#measurements](../../architecture/data-model.md#measurements)

**Objective:** Idempotent upserts with correction and deletion history.

## Outputs
- Versioned dedupe-key builder
- Upsert, supersede and tombstone for measurements, groups, sleep with stages, workouts with segments
- Device and origin upsert with relay flagging
- `resolution_dirty` marks in the same transaction
- ADR-016

## Done when
- 3× replay gives an identical hash of active rows.
- A value change gives one superseded and one new row.
- Tombstone sets `deleted_at` only.
- Reconnecting the same account creates zero duplicates.
