# J07.5 normalize_batch job and reprocess

Epic: [E07 Normalization framework and provenance](README.md) · Status: todo · Depends on: J07.4, J06.1
Read: [reliability#job-queue](../../architecture/reliability.md#job-queue), [connectors#normalizer-contract](../../architecture/connectors.md#normalizer-contract)

**Objective:** Normalization runs async, failures never lose raw data, and raw can be re-normalized.

## Outputs
- `normalize_batch` handler: one transaction per payload, panic isolation, statuses and warnings
- `vitamux reprocess --normalizer --stream --since --until` + job; metadata-only update when unchanged; summary

## Done when
- A panicking payload → `normalize_failed` while the rest of the batch succeeds.
- Version bump + reprocess updates unchanged rows' version and supersedes changed rows; a second run is a no-op.
