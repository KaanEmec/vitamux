# J18.1 Upstream and API verification, ADR, fixtures

Epic: [E18 Garmin Connect connector](README.md) · Status: in progress · Depends on: J04.1
Read: [connectors#third-party-collectors](../../architecture/connectors.md#third-party-collectors), [metric-catalog](../../architecture/metric-catalog.md), [project#synthetic-fixtures-policy](../../architecture/project.md#synthetic-fixtures-policy)

**Objective:** Replace assumptions about `garminconnect` and Garmin Connect with verified facts before any code depends on them.

## Outputs
- An ADR choosing the upstream: `python-garminconnect` against the alternatives (deprecated `garth`, tools with their own storage such as GarminDB, the official Health API), with release cadence, maintainers, license of the full dependency tree (`curl_cffi`, `requests`, `ua-generator`) and the conditions under which Vitamux would switch.
- `docs/providers/garmin.md`, in the shape of [providers/withings.md](../../providers/withings.md):
  - **Auth:** the SSO and MFA steps, what a session consists of, token lifetimes and refresh, and whether the library can load and dump tokens from memory instead of `garmin_tokens.json` (the sidecar is stateless).
  - **Raw access:** whether each needed call can return the endpoint's JSON verbatim (for example through the library's generic `connectapi` call) rather than a reshaped object.
  - **Endpoints per stream:** daily summary, intraday HR, steps, stress and Body Battery, sleep, HRV, SpO2, respiration, activities and FIT download, body composition, blood pressure, VO2max, training readiness and status; their granularity, history depth, paging and date parameters.
  - **Time:** which fields are local, which are GMT, and how the user's timezone is reported.
  - **Recalculation:** how many days back Garmin revises data (sets each stream's correction lookback).
  - **Limits:** 429 and bot-protection behaviour, safe request rates, account-lock risk.
- A Garmin ShapeWriter in `tools/fixturegen` that writes synthetic raw payloads per endpoint, including MFA and error responses.
- An owner check with a real account that records only shape fingerprints and field lists, never values.

## Done when
- Every point above is marked confirmed or corrected in `docs/providers/garmin.md`, and the architecture docs are updated where they differ.
- The ADR is accepted.
- Fixtures pass the privacy guard.
