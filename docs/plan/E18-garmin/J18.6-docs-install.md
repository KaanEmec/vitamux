# J18.6 Install, docs and real-account check

Epic: [E18 Garmin Connect connector](README.md) · Status: todo · Depends on: J18.5, J17.4
Read: [install.md](../../install.md), [operations/troubleshooting.md](../../operations/troubleshooting.md)

**Objective:** A self-hoster enables Garmin from the docs alone and knows the risks of an unofficial source.

## Outputs
- Compose profile `garmin` and the Coolify variant, using the `stable` image with a documented digest-pin alternative.
- `docs/providers/garmin.md`: what syncs, the unofficial status and its risks (terms of service, account lock, breakage after Garmin changes), MFA, reauth, and the pacing of a first backfill.
- Troubleshooting entries: `needs_reauth` after a Garmin login change, `schema_drift` until a fixed upstream lands, rate limiting.
- [faq.md](../../faq.md) updated. A manual real-account checklist for the owner, as for [Withings](../../providers/withings.md#manual-real-account-checklist).

## Done when
- A clean install with the profile enabled connects a real account by following the docs only.
- The owner's checklist passes: a year of history and a week of incremental syncs, spot-checked against Garmin Connect.
