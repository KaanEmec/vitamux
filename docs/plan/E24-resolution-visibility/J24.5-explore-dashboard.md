# J24.5 Explore and dashboard show every source

Epic: [E24 Resolution defaults, opt-in gates and visible data](README.md) · Status: done · Depends on: J24.1, J25.1
Read: [frontend#chart-grammar](../../architecture/frontend.md#chart-grammar), [api#owner-endpoints-apiv1](../../architecture/api.md#owner-endpoints-apiv1)

**Objective:** Whatever a source sent is visible: the metric page never says "No values" while a source has data, and total energy has a place on the dashboard.

## Outputs
- Metric page (`web/src/routes/(app)/explore/[metric]/+page.svelte`): when the resolved series is empty but `/sources/series` has points, draw the source series with every source chip on, and say why nothing resolved.
- Explore list: a metric with only daily totals from a source still lists that source and its latest value.
- Dashboard: `total_energy` joins the default cards (`internal/api/dashboard.go` and `web/src/lib/dashboard/layout.ts`) with a label; edit mode offers cards for metrics that gained data since the layout was saved.

## Done when
- Playwright: a metric with only source data shows the source series; the dashboard shows a total-energy card on the synthetic dataset.
