## Outputs
- Normalizers per stream with the codes in the epic; Polar watches are device type `watch`, the Verity Sense `arm_band`, H10 `chest_strap`; sleep from the hypnogram change points; ISO 8601 durations to seconds; Elixir core temperature under an estimated code, never `body_temperature`.
- The `polar_*` codes in the catalogue with `NoBuiltin` reasons; field ledgers for every stream.

## Done when
