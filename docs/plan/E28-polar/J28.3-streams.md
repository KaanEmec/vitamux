# J28.3 Transaction streams

Epic: [E28 Polar official connector](README.md) · Status: todo · Depends on: J28.2
Read: [connectors#runtime-responsibilities](../../architecture/connectors.md#runtime-responsibilities)

**Objective:** Raw-first sync of every AccessLink data type, committing transactions only after the raw is stored.

## Outputs
- Transaction streams (activity, exercise, physical info) and the date-based endpoints (continuous heart rate, sleep, nightly recharge, SpO2, temperature, cardio load) with incremental, correction and bounded backfill plans.
- A transaction is committed only after every raw record of it is stored; a crash before commit re-reads it idempotently.
- Optional pull notifications that only enqueue a sync.

## Done when
- Stream tests on fixtures: a crash before commit replays without duplicates; rate limits and backfill bounds hold.
