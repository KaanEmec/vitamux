# J01.2 Go module, binary skeleton, config, boundaries

Epic: [E01 Repository bootstrap and contributor experience](README.md) · Status: done (2026-10-03) · Depends on: J01.1
Read: [overview#process-modes](../../architecture/overview.md#process-modes), [overview#repository-layout](../../architecture/overview.md#repository-layout)

**Objective:** A single static binary with subcommands, config loading and enforced package boundaries.

## Outputs
- `cmd/vitamux` with `serve`, `migrate`, `version`, `admin` stubs
- `internal/config` (env + `*_FILE`, validation, redacted dump)
- `internal/*/doc.go` per package
- Lint rules for allowed package dependencies

## Done when
- `CGO_ENABLED=0 go build ./cmd/vitamux` yields a static binary; `vitamux version` prints version, commit, schema version.
- Config tests cover `*_FILE` precedence, required fields and redaction.
- A deliberately forbidden import fails lint.
