# J01.4 Web scaffold and embedding

Epic: [E01 Repository bootstrap and contributor experience](README.md) · Status: done (2026-10-03) · Depends on: J01.2
Read: [frontend#technology](../../architecture/frontend.md#technology)

**Objective:** Serve a SvelteKit static SPA from the binary.

## Outputs
- `web/` (SvelteKit adapter-static, TS, svelte-check, ESLint)
- `go:embed` handler with SPA fallback and hashed-asset caching
- Vite dev proxy to `/api`

## Done when
- `make build` embeds the UI; deep links serve `index.html`.
- Built `index.html` passes a strict-CSP test: no `unsafe-inline`; SvelteKit's inline bootstrap is allowed only by hash (`go test -tags webui ./internal/api/`).
