# J25.4 WHOOP mappings

Epic: [E25 Catalogue completeness and mapping corrections](README.md) · Status: done (2026-10-05) · Depends on: J25.1
Read: [providers/whoop](../../providers/whoop.md), [ADR-0019](../../adr/0019-whoop-upstream.md)

**Objective:** WHOOP sleep stages are right and every WHOOP value is catalogued.

## Outputs
- **Sleep stages** on the live upper-case types: `LIGHT` light, `SWS` deep, `REM` rem, `WAKE` awake, `DISTURBANCES` awake, `LATENCY` in bed before sleep onset (feeds latency), anything else a gap with a warning. Session totals leave a stage nil when no event of it exists (the writer sets awake unconditionally today). The provider page lists the real type names.
- **Cycles:** `day_kilojoules` → `total_energy` (daily value at the main sleep's wake, ADR-0009; source unit kJ through the unit table); recovery `spo2` → `spo2_nightly`; `skin_temp_celsius` → `skin_temperature_nightly` (absolute °C); `calibrating` stays raw (no quality flag fits, and measurements have no context); sleep need and debt (`debt_pre`, the debt inside that night's need) → `whoop_sleep_need`, `whoop_sleep_debt`; consistency → `whoop_sleep_consistency`; disturbances → `whoop_sleep_disturbances`; WHOOP's own stage durations stay raw (the cycle cannot write the session the stage events own).
- **Heart rate:** `data = 0` is a gap, never a 0 bpm sample.
- **Workouts:** energy stays kJ in the source and is converted to kcal for the workout; strain, zone durations and altitude gain stay raw (no workout field yet).
- **Body:** not done: the sidecar stores no body measurements, so `whoop_max_heart_rate` and the profile height and weight have no source (the cycle's `day_max_heart_rate` is the day's maximum, a different value).
- **Deep-dive steps** keyed by local date, so the timezone fix ([J24.6](../E24-resolution-visibility/J24.6-stream-reconcile.md)) supersedes rows instead of duplicating them.
- Version bumps and goldens for every changed stream.

## Done when
- Goldens include a night with every event type and a cycle with all fields; reprocessing gives sessions with deep and awake stages.
- The owner-side value-free checks from the research (stage sums equal the cycle's durations) are recorded in the provider page.
