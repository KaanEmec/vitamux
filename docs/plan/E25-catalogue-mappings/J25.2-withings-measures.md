# J25.2 Withings: device types and measure types

Epic: [E25 Catalogue completeness and mapping corrections](README.md) · Status: done (2026-10-05) · Depends on: J25.1
Read: [providers/withings](../../providers/withings.md), [connectors#withings-connector-reference-pattern](../../architecture/connectors.md#withings-connector-reference-pattern)

**Objective:** Every Withings device is typed, and every measure type Withings documents is mapped or recorded as raw.

## Outputs
- **Device type:** read `modelid` (live responses), fall back to `model_id` (spec), then the `model` string; all can be null on manual entries. Fixture generator and integration fixtures use the live name. Model table: 1–7, 9–12, 14–16, 18 scale; 13 Sleep Analyzer under_mattress (typed scale today); 41–48 bp_monitor (45 = BPM Connect); 51, 54, 58 band; 52, 53, 55, 59, 90–95 watch; 60–63 under_mattress; 70, 71 thermometer; 1051–1060 relays from phone apps (relayed, never counted twice).
- **Measure types:** meastype 12 is generic temperature: body temperature only from a thermometer, else a warning. Add AFib results (130, 139) as events, ECG intervals (135–138, unit checked on a real sample), nerve scores (167, 196), segmental composition (173–175 by `position`, so the duplicate check includes position), metabolic age (227), ESC (229), U-Scan types.
- `withings.measures` normalizer version bump and goldens; `docs/providers/withings.md` updated with the verified field names.

## Done when
- Goldens for a BPM, a scale, a Sleep Analyzer and a manual entry; reprocessing typed devices fills `device_type` and the blood-pressure built-in matches.
