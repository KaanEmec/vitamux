# J04.1 Synthetic world generator

Epic: [E04 Synthetic fixtures and test harness](README.md) · Status: done (2026-10-03) · Depends on: J01.2
Read: [project#synthetic-fixtures-policy](../../architecture/project.md#synthetic-fixtures-policy), [resolution#edge-cases](../../architecture/resolution.md#edge-cases)

**Objective:** A realistic, fictional multi-source year.

## Outputs
- `tools/fixturegen` emitting canonical truth (only `v1` codes from [metric-catalog](../../architecture/metric-catalog.md)) plus a `ShapeWriter` interface for provider-shaped raw output
- Scenarios: high-frequency HR, minute HR, irregular phone/watch samples, steps intervals + daily totals, BP and weigh-ins, two-source sleep with split and partial nights, HealthKit relays and iPhone+Watch overlap, DST, a travel tz change, gaps, corrections, deletions

## Done when
- `make fixtures SEED=42` is byte-identical across runs and platforms.
- `fixtures/README.md` maps scenarios to resolution edge cases.
