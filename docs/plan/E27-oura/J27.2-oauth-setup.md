**Objective:** Connect an Oura account from the panel.

## Outputs
- Connector descriptor, `Authenticator` and `AppConnector` (client id and secret from the setup wizard or `VITAMUX_OURA_*`), callback `/oauth/oura/callback`, refresh with the single-flight path; settings in `internal/config` and `docs/configuration.md`.
- Setup wizard step and verify (`unverifiable` if Oura offers no grant-free check).
