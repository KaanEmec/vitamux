# J27.3 Streams

Epic: [E27 Oura official connector](README.md) · Status: todo · Depends on: J27.2
Read: [connectors#runtime-responsibilities](../../architecture/connectors.md#runtime-responsibilities)

**Objective:** Raw-first sync of every Oura collection.

## Outputs
- One stream per collection in the epic, with incremental, correction and backfill plans, `next_token` paging, rate-limit handling, and raw records keyed by Oura's document id.
- Optional webhook subscription that only enqueues a window sync; polling stays on.

## Done when
- Stream tests on fixtures cover paging, a 429 with Retry-After and a changed document (new raw version).
