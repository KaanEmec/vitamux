**Objective:** Sustainable UI quality.

## Outputs
- Playwright in CI on a seeded synthetic stack; axe; bundle budget; strict svelte-check

## Done when
- All gates are required in CI: each is a step of a required job (`web`: `npm run check` with `--fail-on-warnings`, `npm run budget`, `npx playwright test` incl. axe; `integration`: the real-stack smoke).

## Tasks
- [x] T11.6.1 Wire Playwright into CI. The `web` job runs the 42 stubbed-API specs (project `chromium`). The `integration` job (Postgres 18 leg only) builds the SPA and runs [`scripts/e2e-stack.sh`](../../../scripts/e2e-stack.sh): throwaway database, `vitamux migrate up`, generated owner via `admin create-owner`, `vitamux serve` built with `-tags webui`, then `playwright --project=stack` (`web/e2e-stack/smoke.spec.ts`: sign in, open Today, Data and Settings, every `/api/v1` answer after sign-in is 2xx). Locally: `make test-e2e-stack`. `GET /resolved/daily` and `GET /metrics` may still 404 there (J10.3/J10.4 not served yet); the allow-list in the spec shrinks as they land.
- [x] T11.6.2 Add axe. `@axe-core/playwright` (pinned) in `web/e2e/a11y.spec.ts` scans login, Today, connections list and detail tabs, data daily, drilldown (and its override dialog), sleep, workouts, rules catalogue, metric page and builder steps 2 to 5, lab list, extract dialog, review and results, and every settings page, in light and dark. Serious or critical violations fail; none were found, so no component needed a fix.
- [x] T11.6.3 Add the bundle budget check. `web/scripts/bundle-budget.mjs` (`npm run budget`) gzips the shell preloads, root layout, route nodes and their static imports per route and fails above 300 KiB.
- [x] Strict svelte-check: `npm run check` runs `svelte-check --fail-on-warnings` with `strict` in tsconfig (0 errors, 0 warnings over 592 files).
