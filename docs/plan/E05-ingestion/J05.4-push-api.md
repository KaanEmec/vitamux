# J05.4 Push ingest API and heartbeat

Epic: [E05 Ingestion contract and raw archive](README.md) · Status: done (2026-10-03) · Depends on: J05.1, J05.3, J03.3
Read: [connectors#push-ingest-contract](../../architecture/connectors.md#push-ingest-contract), [api#ingest-endpoints-apiingestv1](../../architecture/api.md#ingest-endpoints-apiingestv1)

**Objective:** Clients, devices and importers can upload raw batches.

## Outputs
- `POST /batches`, `POST /batches/{id}/blobs`, `GET /batches/{id}`, `POST /heartbeat`
- Idempotency-Key semantics; gzip and ratio limits
- Enqueue `normalize_batch`; batch status aggregation; heartbeat into `clients.metadata` / `sync_cursors`

## Done when
- Same key and body → same response; same key with a different body → 409; over limit → 413; wrong connection → 403.
- Batch parser fuzz target runs in CI.
- Batch status reports normalization outcomes.
