# J05.2 Blob store (ADR-004)

Epic: [E05 Ingestion contract and raw archive](README.md) · Status: done (2026-10-03) · Depends on: J02.4, J03.1
Read: [overview#key-decisions](../../architecture/overview.md#key-decisions), [reliability#backup-and-restore](../../architecture/reliability.md#backup-and-restore)

**Objective:** Content-addressed immutable storage for raw payloads and files.

## Outputs
- `internal/blob`: filesystem backend, sha256 addressing with HMAC file names, zstd, atomic write (tmp + fsync + rename + dir fsync), verified read, encryption hook
- `sweep_blobs` job
- ADR-004

## Done when
- Crash injection between blob write and row insert leaves an orphan swept only after the grace period.
- A corrupted blob is detected on read.
