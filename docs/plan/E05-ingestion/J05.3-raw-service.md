# J05.3 Raw payload service

Epic: [E05 Ingestion contract and raw archive](README.md) · Status: done (2026-10-03) · Depends on: J05.2
Read: [connectors#runtime-responsibilities](../../architecture/connectors.md#runtime-responsibilities), [data-model#tables](../../architecture/data-model.md#tables)

**Objective:** One transactional entry point for storing raw records.

## Outputs
- `ingest.StoreRaw(ctx, conn, items)` → `stored|duplicate|new_version`
- Versioning and `supersedes_id`
- Shape fingerprint
- `request_meta` sanitizer
- Quarantine transitions

## Done when
- Same content → duplicate with no new rows; changed content → `new_version` with version+1.
- Auth params are stripped from `request_meta` (sentinel test).
