# J21.12 Redesign Lab and Settings

Epic: [E21 Panel redesign, dashboard and data exploration](README.md) · Status: todo · Depends on: J21.3, J21.4
Read: [lab-documents#review-and-confirmation](../../architecture/lab-documents.md#review-and-confirmation), [apple-health#origins-and-relays](../../architecture/apple-health.md#origins-and-relays)

**Objective:** Lab review is fast and keyboard-friendly, and Settings follows one consistent pattern, with the same features and APIs.

## Outputs
- **Lab:**
  - an upload dropzone with the consent dialog naming the provider and model;
  - review as a split view: the PDF page with the row outlined, next to the row list and editor;
  - confidence and warnings on each row;
  - keyboard flow: Enter confirms, J and K move between rows, E edits;
  - results by analyte, linked to the trend view ([J21.9](J21.9-specialised-views.md)).
  - Values, labels, units and ranges are shown as printed.
- **Settings:**
  - grouped navigation (You, Sources, Access, Data, System);
  - one card and form pattern across profile, time zones, devices (QR pairing with countdown, origin classification), API keys, AI providers, retention, backups and export, security and system status.

## Done when
- The existing lab, settings and devices e2e specs pass unchanged in behaviour.
- The keyboard review flow is covered by a spec.
