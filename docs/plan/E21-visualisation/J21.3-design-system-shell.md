# J21.3 Design system v2 and app shell

Epic: [E21 Panel redesign, dashboard and data exploration](README.md) · Status: todo · Depends on: J21.1
Read: [frontend#code-layout](../../architecture/frontend.md#code-layout), [frontend#navigation](../../architecture/frontend.md#navigation)

**Objective:** One set of tokens and components that every page uses, inside a new shell.

## Outputs
- **Tokens:** `web/src/lib/styles/tokens.css` and `base.css` rewritten. Light and dark themes, plus a `data-theme` override stored per browser (the theme is a browser convenience, not a server setting).
- **Font:** self-hosted and allowed by the CSP. Numbers use tabular figures.
- **New components** in `web/src/lib/ui/`: Button, Segmented, Tabs, Chip, Badge, Card, Table, Drawer, Dialog (replaces `Modal`), Toast, EmptyState, Skeleton, Select, Toggle.
- **Restyled components:** `TextField`, `StatusIcon` (the six data states), `HealthBadge`, `ProblemAlert`, `ExplainPopover`, `UnofficialBadge`.
- **Shell:** `(app)/+layout.svelte` and `lib/nav.ts` rebuilt with:
  - a collapsible icon sidebar with pinned shortcuts;
  - a top bar with the ⌘K command palette (metrics, connections, rules, settings), the global date context, a sync-status pill and the theme toggle.
- **Login:** the page redesigned.

## Done when
- Every existing page renders in the new shell with no raw colours or sizes.
- The e2e suite passes. axe reports no serious violations in either theme.
- No route's initial JS grows by more than the agreed budget.
