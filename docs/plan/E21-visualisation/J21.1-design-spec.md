# J21.1 Design system v2, UX spec and chart grammar

Epic: [E21 Panel redesign, dashboard and data exploration](README.md) · Status: done (2026-10-04) · Depends on: None
Read: [frontend](../../architecture/frontend.md), [metric-catalog](../../architecture/metric-catalog.md), [resolution#result-shape](../../architecture/resolution.md#result-shape)

**Objective:** Agree on how the whole panel looks and behaves before any code: one design system, the screens, and the rule that picks a chart for each kind of data.

## Outputs
- An approved design canvas with:
  - foundations and the shell;
  - Dashboard (dark), edit mode (light), Explore, metric detail, rule lens;
  - sleep and blood-pressure views;
  - redesigned Connections, Rules, rule builder, Lab review, Settings and login;
  - mobile at 375 px.
- [frontend](../../architecture/frontend.md) updated with:
  - **Navigation:** Dashboard · Explore · Connections · Rules · Lab · Settings; the ⌘K command palette; the global date context; the theme override.
  - **Design system:** tokens, components, density, motion, and the data-status set (direct, fallback, calculated, overridden, partial, no data; each a shape, a colour and a word).
  - **Source colours:** stable per provider, distinct in lightness and not only in hue.
  - **Chart grammar:** the catalogue's aggregation and kind pick the view:
    - intensive → line with band;
    - additive → bars;
    - latest → step line with readings;
    - daily_summary → line with baseline;
    - sleep_derived → stage stack and hypnogram;
    - groups → dumbbells or stacked;
    - events → timeline lanes;
    - labs → points with the printed range.
  - **Copy rules:** neutral language for values, plain language for errors, "as printed" for lab data.

## Done when
- The owner approves the canvas.
- Every E21 acceptance item and every existing E11, E12, E15 and E20 screen maps to an artboard or a written rule.
