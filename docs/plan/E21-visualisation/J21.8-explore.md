# J21.8 Explore and generic metric detail

Epic: [E21 Panel redesign, dashboard and data exploration](README.md) · Status: done (2026-10-04) · Depends on: J21.4, J21.5, J21.6
Read: [frontend](../../architecture/frontend.md) (chart grammar), [api#example-all-sources-drilldown](../../architecture/api.md#example-all-sources-drilldown)

**Objective:** Everything synced is one click away, and each item gets a good view without code written for it.

## Outputs
- **`/explore`:** the inventory grouped by section.
  - Search by name, code, device or analyte.
  - Filter by provider, device and origin.
  - Toggle catalogue items with no data.
  - Each row shows: pin, sparkline, latest value, sources, days with data, last record.
- **`/explore/[metric]`:** a metric detail page.
  - The chart comes from `chartFor`, with a range picker and brush.
  - Overlays: baseline band, source series (J21.6) and coverage strip.
  - A stats row and a values table.
  - Every point opens its explanation, provenance and `OverrideDialog`.
  - A "How it's calculated" button opens the rule lens ([J21.10](J21.10-rule-lens.md)).
- **Existing routes:** `/data/*` redirect to Explore. The single-day all-sources drilldown becomes a sub-view. The daily, sleep and workout pages move to the typed endpoints, which closes the open item in [J11.3](../E11-frontend/J11.3-data-provenance.md).

## Done when
- Every metric code in the synthetic dataset opens a view with no console errors.
- The provenance and override flows from E11 still pass.
