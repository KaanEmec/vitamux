# J21.9 Specialised views

Epic: [E21 Panel redesign, dashboard and data exploration](README.md) · Status: todo · Depends on: J21.8
Read: [resolution#sleep-episode-alignment](../../architecture/resolution.md#sleep-episode-alignment), [resolution#group-coherent-selection](../../architecture/resolution.md#group-coherent-selection), [lab-documents#review-and-confirmation](../../architecture/lab-documents.md#review-and-confirmation)

**Objective:** Events and groups get views that fit their shape instead of a scalar line.

## Outputs
- **Sleep:**
  - stages per night (stacked);
  - a bed and wake consistency chart;
  - last night across sources, with aligned hypnograms and the selected source.
- **Blood pressure:**
  - systolic and diastolic dumbbells, with pulse;
  - the readings table, with manual entry.
  - No categories or thresholds.
- **Body composition:** weight with component stacks.
- **Workouts:** a calendar and a list with clusters (`/resolved/workouts`).
- **Events:** timeline lanes per event type.
- **Lab analytes:** a trend with the printed reference range, shown as printed and with no added flags. Linked from the Lab section ([J21.12](J21.12-redesign-lab-settings.md)).

## Done when
- Each view has e2e coverage on fixtures, including a night with naps and a multi-source sleep.
- Copy contains no judgement words (checked by a lint list in the e2e suite).
