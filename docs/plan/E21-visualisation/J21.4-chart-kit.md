# J21.4 Chart kit

Epic: [E21 Panel redesign, dashboard and data exploration](README.md) · Status: done (2026-10-04) · Depends on: J21.2, J21.3
Read: [frontend](../../architecture/frontend.md) (chart grammar, from J21.1), ADR-0020 (from J21.2)

**Objective:** Small, reusable chart components so that pages never draw charts by hand.

## Outputs
- `web/src/lib/charts/` with:
  - TimeSeries (line, area, band);
  - Bars, RangeDumbbell, StepDots, StageStack, Sparkline;
  - StatCard, CoverageStrip, EventLanes;
  - RangePicker (1D/1W/1M/3M/1Y/All plus brush);
  - ChartTooltip (value, status, coverage, "explain").
- Shared source colours and status markers.
- Reduced motion, keyboard focus per point, and a `<table>` fallback for every chart.
- `SeriesChart`, `Hypnogram` and `CoverageHeatmap` moved onto the kit.
- A `chartFor(metric)` helper that applies the chart grammar to `GET /metrics` metadata.

## Done when
- Each component has a Playwright spec on fake data, covering both themes and keyboard focus.
- The kit loads as a lazy chunk within the ADR-0020 budget.
