# J21.7 Dashboard

Epic: [E21 Panel redesign, dashboard and data exploration](README.md) · Status: todo · Depends on: J21.4, J21.6
Read: [frontend#navigation](../../architecture/frontend.md#navigation)

**Objective:** The first page shows the day at a glance and can be arranged by the owner.

## Outputs
- `(app)/+page.svelte` replaced with Dashboard.
- **Curated default cards:**
  - sleep (hero, with a stage bar);
  - resting HR, HRV, steps;
  - VO₂ max, weight, blood pressure, SpO₂, respiratory rate, active energy.
  - Cards with no data stay hidden until a source provides it.
- **Each card shows:**
  - the value and unit;
  - a status glyph and word;
  - a neutral delta against a baseline;
  - a sparkline;
  - source chips.
- **Edit mode:** pin from Explore, drag to reorder (keyboard alternative: move up and down), S/M/L size, hide, and reset to default.
- **Layout API:** `GET/PUT /api/v1/settings/dashboard` with a versioned layout schema stored on the server. Unknown metrics are dropped on read.
- **Context:** the global date selector shows past days. The alert strip covers connection health and backup age. Empty states link to E20's "Connect a source".

## Done when
- E2E on fake data:
  - default layout;
  - edit and persist across a reload;
  - a past day;
  - empty install.
- The page loads in under 1 s on the synthetic 3-year stack.
