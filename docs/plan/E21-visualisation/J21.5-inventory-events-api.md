# J21.5 Inventory and events API

Epic: [E21 Panel redesign, dashboard and data exploration](README.md) · Status: done (2026-10-04) · Depends on: None
Read: [api#owner-endpoints-apiv1](../../architecture/api.md#owner-endpoints-apiv1), [metric-catalog#events](../../architecture/metric-catalog.md#events), [data-model#tables](../../architecture/data-model.md#tables), [ADR-0015](../../adr/0015-rest-openapi-conventions.md)

**Objective:** Let the panel list everything stored, including health events, which have no endpoint today.

## Outputs
- OpenAPI-first in `api/openapi.yaml` and `api/authz.yaml`.
- **`GET /api/v1/inventory`:** one row per metric, group kind, event code and lab analyte that has data. Each row carries: count, first and last seen, latest value and unit, providers, devices, origins, days with data, and its catalogue metadata.
- **`GET /api/v1/event-types`:** the event catalogue from `internal/catalog/events.go`.
- **`GET /api/v1/events`:** rows from `health_events`. It takes the same filters as `/measurements`, uses keyset paging, and supports `include=provenance`.
- **Implementation:** reuses `internal/catalog`, `source_hourly_aggregates`, the cursor helpers and the provenance rendering. If the query misses its budget, a small summary table is kept up to date by the aggregate rebuild job.
- [api](../../architecture/api.md) updated.
