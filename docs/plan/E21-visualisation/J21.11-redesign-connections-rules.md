# J21.11 Redesign Connections and Rules

Epic: [E21 Panel redesign, dashboard and data exploration](README.md) · Status: done (2026-10-04) · Depends on: J21.3, J21.4
Read: [frontend#navigation](../../architecture/frontend.md#navigation), [frontend#rule-builder](../../architecture/frontend.md#rule-builder)

**Objective:** The two busiest configuration sections become easy to scan and act on, with the same features and APIs.

## Outputs
- **Connections:**
  - provider cards with health, last sync, an unofficial badge, a 14-day run strip, and "Sync now" or the fix-it action;
  - a "Connect a source" card;
  - backfill progress and recent runs;
  - the detail page as a header with tabs (Overview with a sync timeline, Streams, Backfills, History, Settings);
  - the E20 setup wizards restyled, or built on the kit if they come later.
- **Rules:**
  - catalogue cards with the strategy in plain words, the source order and a coverage mini-heatmap, plus custom and built-in filters;
  - the metric page with a version timeline and a side-by-side diff;
  - the builder as a stepper with a live preview sidebar.

## Done when
- The existing connections, rules and rule-chips e2e specs pass unchanged in behaviour.
- axe reports no serious violations.
