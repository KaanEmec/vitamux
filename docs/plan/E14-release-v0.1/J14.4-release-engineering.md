**Objective:** Repeatable releases that install generically.

## Outputs
- Release workflow (multi-arch images, SBOMs, checksums, optional signing, Compose bundle), changelog process, upgrade test from previous rc, checklist
- Clean installs of an rc on a fresh Linux VM and macOS, and on a fresh Coolify instance (not the reference VPS), using only the docs

## Done when
- An rc tag produces all artifacts; the upgrade test preserves data.
- All clean installs succeed and every friction point is fixed or documented.
