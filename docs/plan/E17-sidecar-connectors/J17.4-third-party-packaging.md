# J17.4 Third-party collector packaging, licensing and guide

Epic: [E17 Remote sidecar connectors and third-party collectors](README.md) · Status: done · Depends on: J17.3, J14.2
Read: [connectors#third-party-collectors](../../architecture/connectors.md#third-party-collectors), [project#license-and-notices](../../architecture/project.md#license-and-notices)

**Objective:** Wrapping an existing open-source collector is a documented, repeatable task for the community.

## Outputs
- A guide covering both paths (a sidecar wrapping the upstream library, or a push collector wrapping an upstream tool that already schedules itself), plus a decision table
- Layout `sidecars/<name>/`: Dockerfile, upstream pinned by version and digest, `UPSTREAM.md` (repo, license, version, official or unofficial), Compose profile, 256 MiB limit, healthcheck
- A license gate per sidecar image (separate notices, copyleft flagged for review; the core stays MIT)
- Install docs: enabling a sidecar profile in Compose and in Coolify

## Done when
- A contributor wraps the example from the guide alone.
- The license gate fails on a sidecar without `UPSTREAM.md` or with an unreviewed copyleft license.
