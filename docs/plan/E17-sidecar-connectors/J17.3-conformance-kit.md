# J17.3 Conformance kit and example sidecar

Epic: [E17 Remote sidecar connectors and third-party collectors](README.md) · Status: todo · Depends on: J17.1, J17.2
Read: [connectors#remote-sidecar-mode](../../architecture/connectors.md#remote-sidecar-mode)

**Objective:** Sidecar authors can check their work without running Vitamux end to end.

## Outputs
- `vitamux connector-test --url --secret-file [--scenario]`: checks the schemas, auth steps, paging and cursors, idempotent replay, typed errors, Retry-After, drift reporting, and that logs and errors contain no secrets
- `examples/sidecar-python/`: a small sidecar in a non-Go language, serving synthetic data, with a Dockerfile, a Compose profile and a normalizer in Go
- A CI job that runs the kit against the example

## Done when
- The example passes. Deliberately broken variants each fail with one clear, named check.
