# J12.4 Validation and review API

Epic: [E12 Blood-test documents](README.md) · Status: done (2026-10-03) · Depends on: J12.3, J12.5, J03.4
Read: [lab-documents#validation](../../architecture/lab-documents.md#validation), [lab-documents#review-and-confirmation](../../architecture/lab-documents.md#review-and-confirmation)

**Objective:** Deterministic checks and mandatory human confirmation with an audit trail.

## Outputs
- Re-parse value/comparator/range; text-layer evidence check; unit, date and duplicate checks; analyte suggestions from the J12.5 aliases
- Row edit, accept and reject endpoints; confirm transaction; revisions; run comparison

## Done when
- Seeded model errors (wrong decimal, swapped units, invented row, ambiguous date) each produce the expected warning.
- Confirm fails while rows are unreviewed or required fields are missing.
- A confirmed result traces to document, page, evidence, run, versions and edits.
