**Objective:** An efficient, safe review experience.

## Outputs
- Upload; consent dialog naming provider and model; pdf.js viewer with evidence highlight; row editor with warnings; confirm; results by analyte with printed ranges; delete flow
- Extraction evaluation command (field precision/recall on the synthetic corpus)

## Done when
- E2E with the fake: upload, extract, edit, reject, confirm, history, delete keeping derived data.
- Copy review finds no interpretive language.
- Evaluation recorded for fake and at least one real provider (synthetic PDFs only).
