# J12.1 Document schema and storage

Epic: [E12 Blood-test documents](README.md) · Status: done (2026-10-03) · Depends on: J05.2, J03.1, J10.1
Read: [lab-documents#storage](../../architecture/lab-documents.md#storage)

**Objective:** Private storage of original PDFs.

## Outputs
- Migrations: `documents`, `document_keys`, `extraction_runs`, `lab_extracted_rows`, `extraction_row_edits`, `lab_reports`, `lab_results`, `lab_result_revisions`, `analytes`, `analyte_aliases`
- Upload with validation (magic, size, pages, encrypted reject); per-document key; sha256 dedupe; retention; deletion modes

## Done when
- Non-PDF, oversized, encrypted and too-many-pages files are rejected with codes.
- Re-upload links the existing document.
- After deletion the blob is unreadable even with the master key; audit has no content.
