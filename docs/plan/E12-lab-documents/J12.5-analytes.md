# J12.5 Analyte catalogue and conversions

Epic: [E12 Blood-test documents](README.md) · Status: done (2026-10-03) · Depends on: J12.1
Read: [analyte-catalog](../../architecture/analyte-catalog.md) · [lab-documents#review-and-confirmation](../../architecture/lab-documents.md#review-and-confirmation)

**Objective:** Normalize known analytes without losing laboratory originals.

## Outputs
- Seed catalogue from [analyte-catalog.md](../../architecture/analyte-catalog.md) (codes, names, canonical units, analyte-specific factors, optional LOINC field)
- `analyte-catalog.md` reduced to its rules once the seed is generated
- Alias API
- Conversion tests

## Done when
- Conversions tested (e.g., glucose mg/dL ↔ mmol/L), including the affine HbA1c case.
- No-conversion pairs (Lp(a) nmol/L ↔ mg/dL, D-dimer FEU ↔ DDU) are refused, not converted.
- LOINC codes come only from a verified lookup.
- Unknown analytes stay confirmable.
- Original label and unit are always stored.
