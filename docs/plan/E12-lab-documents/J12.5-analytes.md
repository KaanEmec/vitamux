# J12.5 Analyte catalogue and conversions

Epic: [E12 Blood-test documents](README.md) · Status: todo · Depends on: J12.1
Read: [lab-documents#review-and-confirmation](../../architecture/lab-documents.md#review-and-confirmation)

**Objective:** Normalize known analytes without losing laboratory originals.

## Outputs
- Seed catalogue (codes, names, canonical units, analyte-specific factors, optional LOINC field)
- Alias API
- Conversion tests

## Done when
- Conversions tested (e.g., glucose mg/dL ↔ mmol/L).
- Unknown analytes stay confirmable.
- Original label and unit are always stored.
