# J09.1 Rule schema v1 and validator

Epic: [E09 Resolution engine](README.md) · Status: done (2026-10-03) · Depends on: J07.1 · Produces: **G2**
Read: [resolution#rule-specification](../../architecture/resolution.md#rule-specification), [resolution#selectors-and-validation](../../architecture/resolution.md#selectors-and-validation)

**Objective:** Freeze the rule language before the engine and UI depend on it.

## Outputs
- `schemas/resolution-rule.v1.json`, Go types, validator with field-path errors. Schema v1 includes the MVP [extensions](../../architecture/resolution.md#extensions): `contexts` (E1), `within_source.statistic` (E2: `min_rolling_mean`, `min`; plus `latest`/`mean` for grouped metrics), `quality.require_wear` (E3), `follow` (E5), `compose` (E9), and the sleep-family rule (`metric: sleep`)
- Warning catalogue (`cross_source_sum_duplicate_risk`, `composite_exceeds_any_source`, `insufficient_sources`, `preferred_source_unavailable`, `definition_changed`, `follow_unavailable`, …)
- ADR-008 (rule schema), ADR-009 (sleep date and night window)

## Done when
- The four example rules from CLAUDE.md (as v1) validate; ≥ 12 seeded invalid rules fail with precise errors.
- One example rule per MVP extension validates. The validator rejects: `contexts` naming unknown groups, `follow` cycles or a leader with an incompatible window, `require_wear` on a metric without buckets, `compose` on a non-additive metric, and a per-code rule for a sleep code.
- A cross-provider `mean` on a provider-namespaced score ([metric-catalog#rules](../../architecture/metric-catalog.md#rules)) fails validation.
- Both ADRs accepted.

**G2 accepted (2026-10-03).** Schema `schemas/resolution-rule.v1.json` ([ADR-0008](../../adr/0008-rule-schema.md)) and sleep date / night window ([ADR-0009](../../adr/0009-sleep-date-night-window.md)). The CLAUDE.md examples (mean across sources, first_available ladder, Apple Watch first excluding relayed Garmin, acknowledged sum), one rule per extension, both rule families and every row of [resolution-defaults](../../architecture/resolution-defaults.md) that has a catalogue code are expressible; tests: `internal/resolve/validate_test.go`.
