# J09.2 Built-in defaults, rule storage and versioning

Epic: [E09 Resolution engine](README.md) · Status: todo · Depends on: J09.1, J03.4
Read: [resolution#selectors-and-validation](../../architecture/resolution.md#selectors-and-validation)

**Objective:** Safe defaults for every metric, plus immutable user rule versions.

## Outputs
- `builtin:<metric>:1` defaults in code (mostly `first_available`, relay exclusion when the relayed provider is connected)
- Generated `docs/resolution-defaults.md`
- Migrations `resolution_rules`, `active_rules`; create version, activate, history, diff; audit

## Done when
- Every catalogue metric has a valid default.
- An edit creates version+1; reactivating an old version works; audit shows actor and diff.
