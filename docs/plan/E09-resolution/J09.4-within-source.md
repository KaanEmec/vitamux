## Outputs
- Intensive bucket-mean aggregator; additive pro-rating and `daily_value_policy`; latest (with `within_source.statistic: latest | mean` for grouped metrics on `local_day`); daily_summary; group-coherent selection; `intra_group` policies

## Done when
- Property: duplicating the samples in a bucket N times does not change the window value.
- Pro-rating tests pass.
- A daily total is never summed with intervals.
