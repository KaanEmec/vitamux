# J22.9 Specialised views

Epic: [E22 Vitamux iOS app](README.md) · Status: done (2026-10-05) · Depends on: J22.8
Read: [resolution#sleep-episode-alignment](../../architecture/resolution.md#sleep-episode-alignment), [E21 J21.9](../E21-visualisation/J21.9-specialised-views.md)

**Objective:** Sleep, blood pressure, body composition, workouts, events and lab analytes get the same dedicated views as in the panel.

## Outputs
- **Sleep** (`/sleep?include=stages`, `/resolved/sleep`): stage bars per night, bed and wake times, stats; a night opens hypnograms side by side across sources, naps, and provenance.
- **Blood pressure** (`/blood-pressure`): dumbbells, pulse line, stats, readings with provenance. No categories or colouring by value.
- **Body composition** (`/groups?kind=body_composition`): weight per source, fat-free and fat mass stacked, weigh-ins with provenance.
- **Workouts** (`/resolved/workouts`): month calendar with counts, overlapping workouts grouped one row per source with the rule's pick marked, energy and heart rate, provenance.
- **Events** (`/inventory`, `/events`): one lane per type on a shared axis, a single-type filter, table fallback.
- **Lab analyte** (`/lab-results`): points in one printed unit with the printed range as a band, values and flags as printed; also for `label:` analytes.
- All page with `cursor` and `limit` like the panel.

## Done when

## Notes
- Code: `apple/VitamuxApp/Sources/Features/Specialised` (`Sleep/` with the night across sources, `BloodPressure/`, `BodyComposition/`, `Workouts/` with the month calendar, `Events/`, `LabAnalyte/`, `Shared/` for paging, range, labels and small rows). Each view has one `@Observable` model calling the generated client; paged lists follow `next_cursor` to the end (at most 50 pages), as the panel's `readAll`.
- The lab analyte view is the `vitamux://lab/analytes/{code}` screen (also `label:<printed label>`); J22.12 links to it from the results list.
- Fat-free and fat mass are stacked in a small chart of the view's own (`CompositionBars`), because the kit's stacked `Bars` colour by sleep stage only. The kit's callout rows (`ChartTip.Row`) have no public initializer, so blood-pressure dumbbells show the pair alone; pulse, context and source are in the pulse chart and the readings list.
- Fixtures: `FakeServer+Specialised.swift` (pages of at most 25 rows, so clients walk the cursor), checked by `SpecialisedFakeTests`; UI tests in `SpecialisedUITests`, including an empty range per view, the three-source night with a nap the day before, and a judgement-word check over every view's text (the panel's list in `web/e2e/views.spec.ts`).
