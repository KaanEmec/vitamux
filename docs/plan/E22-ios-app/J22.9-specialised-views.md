# J22.9 Specialised views

Epic: [E22 Vitamux iOS app](README.md) · Status: todo · Depends on: J22.8
Read: [resolution#sleep-episode-alignment](../../architecture/resolution.md#sleep-episode-alignment), [E21 J21.9](../E21-visualisation/J21.9-specialised-views.md)

**Objective:** Sleep, blood pressure, body composition, workouts, events and lab analytes get the same dedicated views as in the panel.

## Outputs
- **Sleep** (`/sleep?include=stages`, `/resolved/sleep`): stage bars per night, bed and wake times, stats; a night opens hypnograms side by side across sources, naps, and provenance.
- **Blood pressure** (`/blood-pressure`): dumbbells, pulse line, stats, readings with provenance. No categories or colouring by value.
- **Body composition** (`/groups?kind=body_composition`): weight per source, fat-free and fat mass stacked, weigh-ins with provenance.
- **Workouts** (`/resolved/workouts`): month calendar with counts, overlapping workouts grouped one row per source with the rule's pick marked, energy and heart rate, provenance.
- **Events** (`/inventory`, `/events`): one lane per type on a shared axis, a single-type filter, table fallback.
- **Lab analyte** (`/lab-results`): points in one printed unit with the printed range as a band, values and flags as printed; also for `label:` analytes.
- All page with `cursor` and `limit` like the panel.

## Done when
- UI tests per view on the fake server, including an empty range and a multi-source night.
- Copy review: nothing rates a value.
