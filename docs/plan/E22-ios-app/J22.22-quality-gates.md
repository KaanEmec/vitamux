# J22.22 Quality gates and CI

Epic: [E22 Vitamux iOS app](README.md) · Status: in progress · Depends on: J22.7–J22.21
Read: [project#testing-levels](../../architecture/project.md#testing-levels), [E21 J21.13](../E21-visualisation/J21.13-quality-release.md)

**Objective:** The app is held to the same bar as the panel: tested on every screen, accessible, fast, and private.

## Outputs
- **CI:** the `swift` job runs both packages' tests, the allowed-package check (`Package.resolved` holds only Apple's swift-openapi packages), an `xcodebuild` of the app and widget for the simulator, and the UI test suite on the fake server.
- **Stack smoke:** `make test-ios-stack` starts a real server on a throwaway database with synthetic data (as `scripts/e2e-stack.sh` does) and runs a simulator flow: server step, sign-in with TOTP, dashboard, a metric, an override, a fake Withings connection, sign-out.
- **Parity review:** the [parity matrix](../../architecture/ios-app.md#parity-matrix) is ticked row by row against the app, and any panel feature added since J22.1 gets a row.
- **Lean review:** the code is checked against the [lean architecture](../../architecture/ios-app.md#lean-architecture) rules; any layer, package or abstraction that crept in is removed or justified in ADR-0023.
- **Accessibility:** VoiceOver labels and order, the largest accessibility Dynamic Type size, Reduce Motion, Increase Contrast, and status never by colour alone; a `performAccessibilityAudit()` UI test per screen.
- **Performance:** signposts for dashboard ready and chart render; dashboard under 1 s and a 14,400-point day without dropped frames on the synthetic 3-year dataset.
- **Privacy:** a test runs the UI suite with synthetic values and scans the unified log for them and for tokens; the privacy manifest is validated.

## Done when
- CI is green with every gate above.
- No serious accessibility audit failures on any screen.
