# J22.20 Home-screen and lock-screen widgets

Epic: [E22 Vitamux iOS app](README.md) · Status: todo · Depends on: J22.7, J22.19
Read: [ios-app#offline-cache-widgets-and-notifications](../../architecture/ios-app.md#offline-cache-widgets-and-notifications)

**Objective:** Glanceable dashboard metrics outside the app, private by default.

## Outputs
- Widget extension with small (one metric), medium (up to three) and lock-screen accessory (one value) families.
- Configuration through an App Intent that lists the dashboard's metrics (`/settings/dashboard`, `/metrics`).
- Content: value and unit, status shape and word, neutral delta, sparkline, "as of" time; the same summary data as the dashboard card.
- Timeline: reads the shared cache and refreshes it with the app session within the widget budget; a revoked or expired session shows "Open Vitamux to sign in" and no values.
- Privacy: values are `privacySensitive` and redacted while locked unless the owner turns that off.
- A tap opens `vitamux://explore/<metric>`.

## Done when
- Widget previews and tests for each family, locked and unlocked, stale, signed-out.
- Device campaign: widgets refresh over a day without the app opened.
