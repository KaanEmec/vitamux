# J22.20 Home-screen and lock-screen widgets

Epic: [E22 Vitamux iOS app](README.md) · Status: done · Depends on: J22.7, J22.19
Read: [ios-app#offline-cache-widgets-and-notifications](../../architecture/ios-app.md#offline-cache-widgets-and-notifications)

**Objective:** Glanceable dashboard metrics outside the app, private by default.

## Outputs
- Widget extension with small (one metric), medium (up to three) and lock-screen accessory (one value) families.
- Configuration through an App Intent that lists the dashboard's metrics (`/settings/dashboard`, `/metrics`).
- Content: value and unit, status shape and word, neutral delta, sparkline, "as of" time; the same summary data as the dashboard card.
- Timeline: reads the shared cache and refreshes it with the app session within the widget budget; a revoked or expired session shows "Open Vitamux to sign in" and no values.
- Privacy: values are `privacySensitive` and redacted while locked unless the owner turns that off.
- A tap opens `vitamux://explore/<metric>`.

## Done when
- Widget previews and tests for each family, locked and unlocked, stale, signed-out.
- Device campaign: widgets refresh over a day without the app opened.

## Notes
- Three widgets: Metric (small, medium, lock-screen rectangular, circular, inline; an App Intent lists the dashboard's cards), Sleep (stages) and Metrics (three side by side, medium). Stock WidgetKit views with the chart kit's colours, sparkline and status glyphs.
- Handoff: one `WidgetSnapshot` JSON file in the app group (`Widgets/Shared`, compiled into both targets), written by `Features/Dashboard/WidgetSnapshotWriter.swift` after each load of today (cached answers keep their stored time) and removed on sign-out, an ended session and a new sign-in. The extension has no client and never fetches: values are as fresh as the app's last dashboard load. The timeline adds entries for "stale" (6 hours) and for the session's end (Keychain item gone or expired, or 30 days idle), then shows "Open Vitamux to sign in".
- Redaction: values are `privacySensitive`, drawn as a blurred placeholder under the `.privacy` reason, unless Settings › This app turns it off (app-group key `widgets.redactWhileLocked`; the toggle reloads the timelines).
- Tests: `VitamuxWidgetsTests` (unhosted) renders each family fresh, stale, signed out, locked and unlocked and checks the timeline, session rules and links; `WidgetsUITests` covers the app's side. Left for the device campaign (J22.23): the real lock-screen redaction, and refreshes over a day without opening the app, which need the background refresh to load the dashboard (`DashboardModel.load` then `WidgetSnapshotWriter.write`).
