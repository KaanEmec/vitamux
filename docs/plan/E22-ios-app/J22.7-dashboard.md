# J22.7 Dashboard

Epic: [E22 Vitamux iOS app](README.md) · Status: todo · Depends on: J22.5, J22.6
Read: [frontend#navigation](../../architecture/frontend.md#navigation), [E21 J21.7](../E21-visualisation/J21.7-dashboard.md)

**Objective:** The first tab shows the day at a glance, arranged exactly like the owner's panel dashboard.

## Outputs
- **Day context:** previous and next day, a date picker without future dates, Today, and the owner's timezone label. Pull to refresh.
- **Alerts:** connections needing attention, permanently failed jobs in the last 7 days, stale backup (`GET /connections`, `/jobs?status=dead`, `/system/status`).
- **Cards:** from `GET /settings/dashboard` and `GET /resolved/summary` (batches of 20): value and unit, status, neutral delta against the 30-day mean, sparkline, source chips, partial flag; sleep stages and the blood-pressure pulse line. Cards without data hide outside edit mode. A tap opens Explore.
- **Edit mode:** drag or move up and down, S/M/L size, hide, add metric (searchable catalogue, sleep and BP parts collapsed), reset to default, cancel or save with `PUT /settings/dashboard`. The layout is shared with the panel.
- **Sources:** a health row per connection, or "Connect a source".
- A 404 or 503 leaves a section empty instead of failing the screen.

## Done when
- UI tests on the fake server: default layout; edit, save and reload; a past day; an empty install; a layout saved in the panel shows the same on the phone.
- It opens in under 1 s on the synthetic 3-year dataset (measured in J22.22).
