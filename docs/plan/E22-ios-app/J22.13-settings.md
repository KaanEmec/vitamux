# J22.13 Settings parity

Epic: [E22 Vitamux iOS app](README.md) · Status: todo · Depends on: J22.5
Read: [security#owner-sign-in](../../architecture/security.md#owner-sign-in), [api#exports](../../architecture/api.md#exports), [apple-health#origins-and-relays](../../architecture/apple-health.md#origins-and-relays)

**Objective:** Every Settings page of the panel works on the phone, plus the app's own preferences.

## Outputs
- **Profile** (`/settings`, `/timezone-periods`): account, timezone periods (add, edit with zone suggestions, remove), Withings notifications.
- **Devices** (`/devices`, `/devices/pairing-codes`, `/request-anchor-reset`, `/revoke`, `/origins`): pairing code with QR and countdown for another phone, device list with requested and possibly-denied types, resync all or chosen types, revoke; origins classified native, relayed or direct, and the per-iPhone take/ignore source filter ([J22.25](J22.25-apple-health-source-filter.md)).
- **AI providers:** the `documents.external_ai.*.enabled` toggles.
- **API keys** (`/api-keys`): list with state; create with name, scopes and expiry, the secret shown once with copy and "I have saved it"; revoke.
- **Security:** change password; TOTP enrol (secret, `otpauth://` link to an authenticator app on the same phone, copy), confirm, recovery codes shown once, disable with password and code; sessions with kind and name (J22.2), end one or all others.
- **Sources** (`/settings` key `sources.priority`, `/providers/{provider}/app-credentials`, `/sidecars`): source order, provider apps through J22.11's wizard, sidecars added (secret shown once) or removed.
- **Retention:** typed controls for document and raw retention settings, the per-provider raw days map, and unknown keys shown generically.
- **Backups and export:** last backup; export as NDJSON or CSV with or without raw, 1 s polling, the file downloaded with the bearer session and handed to the share sheet or Files.
- **System status:** versions (server and app, `api_version`), database and blob sizes, degraded connections, failing jobs.
- **App preferences** (local): theme, app lock and timeout, notification categories (J22.21), clear the cache (J22.19), widget redaction (J22.20), server and sign-out.

## Done when
- UI tests for every page and every destructive action's confirmation.
- Secrets shown once (API key, recovery codes) are not in the cache, logs or snapshots.
