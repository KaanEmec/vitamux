# J22.6 Native chart kit and chart grammar

Epic: [E22 Vitamux iOS app](README.md) · Status: todo · Depends on: J22.4
Read: [ios-app#charts](../../architecture/ios-app.md#charts), [frontend#chart-grammar](../../architecture/frontend.md#chart-grammar), [resolution#display-rollups](../../architecture/resolution.md#display-rollups)

**Objective:** Every kind of data gets a good, accessible native chart without code per metric.

## Outputs
- **Chart views** in VitamuxKit's `Charts/` folder, on Swift Charts:
  - `TimeSeries` (line, band, step, baseline, dots), `Bars` (plain and stacked by stage), `Hypnogram`, `RangeDumbbell`, `EventLanes`, `Sparkline`, `CoverageStrip`;
  - `RangePicker` (1W, 1M, 3M, 1Y, All), selection with a callout, pinch or drag to zoom;
  - status markers (shape, colour and word), source series that differ by dash and colour, a ghost draft series, baseline band;
  - min/max decimation per pixel column above about 2,000 points.
- **Grammar:** `chartFor(metric)` from catalogue metadata, the Swift twin of `web/src/lib/charts/grammar.ts`.
- **Shared fixture:** `fixtures/chart-grammar.json` (catalogue entries and expected views), checked by VitamuxKit's tests and, on the web side, by a Playwright spec that imports `grammar.ts`, so no new test runner is added.
- **Accessibility:** `AXChartDescriptor` for VoiceOver and Audio Graphs; a "Show as table" fallback for every chart; Reduce Motion respected.
- **Rollups:** week and month grains from `GET /resolved/trend` for long ranges, as the panel does.

## Done when
- Snapshot or preview tests for each view on synthetic data, in light and dark, and at the largest Dynamic Type size.
- A 14,400-point day renders and scrolls without dropped frames on a recent iPhone (measured in J22.22).
- The grammar fixture passes in both test suites.
