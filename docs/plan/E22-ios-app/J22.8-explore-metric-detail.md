# J22.8 Explore, metric detail, overrides and provenance

Epic: [E22 Vitamux iOS app](README.md) · Status: done · Depends on: J22.5, J22.6
Read: [api#example-all-sources-drilldown](../../architecture/api.md#example-all-sources-drilldown), [resolution#manual-overrides](../../architecture/resolution.md#manual-overrides), [resolution#result-shape](../../architecture/resolution.md#result-shape)

**Objective:** Everything stored is a tap away on the phone, and every plotted value can explain itself and be overridden.

## Outputs
- **Explore** (`GET /inventory`, `/resolved/summary`, `/metrics`): sections with 30-day sparkline, latest value, sources, days with data and last record; search; source, device and origin filters; "show metrics without data"; pin and unpin (`/settings/dashboard`); the "aggregates catching up" note. Specialised items open their J22.9 view.
- **Metric detail** (`/metrics/{code}`, `/resolved/daily`, `/resolved/trend`, `/sources/series`, `/coverage`): range picker with an end date (the Day range comes with [J22.26](J22.26-intraday-views.md)), the grammar chart, baseline, source series and coverage toggles, rollup drill-down, 7/30/90-day means, lowest and highest, days with data, a paged values table, pin, rule summary and "Edit rule" (J22.10).
- **Point sheet:** resolved value, status, source, explanation, warnings, rule inputs with their records; actions Exclude an input, Force a source, Set a value (`POST /overrides`); Provenance (`/provenance/{entity}/{id}`).
- **All-sources day:** resolved result, every source's raw readings overlaid (`/resolved/{metric}/{window_key}/sources`, `/measurements` all pages), sources marked used, excluded or not in rule, the day's overrides with Revoke.

## Done when
- Every metric code in the synthetic dataset opens a view with no errors.
- UI tests: each override action, revoke, provenance, and a rollup drill-down.
- Overrides made on the phone appear in the panel's audit trail.
