# J19.5 Lifecycle tests and upstream tracking

Epic: [E19 WHOOP connector](README.md) · Status: in progress · Depends on: J19.3, J19.4, J17.5
Read: [J17.5](../E17-sidecar-connectors/J17.5-upstream-tracking.md), [connectors#typed-errors](../../architecture/connectors.md#typed-errors)

**Objective:** Prove the full lifecycle end to end, and put the sidecar on automatic upstream tracking.

## Outputs
- A core integration test using the sidecar in replay mode: connect with MFA, backfill, incremental, rescoring, refresh-token rotation, revoked session (→ `needs_reauth`), 429 (→ blocked until Retry-After), changed shape (→ `degraded: schema_drift`, raw quarantined, no substitution).
- `sidecars/whoop/` enrolled in J17.5:
  - a daily Dependabot entry grouping `@dofek/whoop` with its lockstep `@dofek/*` packages;
  - the auto-merge checks: sidecar tests, conformance kit, Go goldens on replayed raw, license gate;
  - a nightly canary that builds `packages/whoop-whoop` from `Asherlc/dofek` main;
  - the `stable` image.
- Lockstep releases are coalesced: at most one bump PR per day, always to the newest version.

## Done when
- The lifecycle test passes in CI.
- A simulated `@dofek/whoop` release is merged and published as `stable`. A simulated breaking release is held with `upstream-break`.
