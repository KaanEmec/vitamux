# J19.6 Install, docs and real-account check

Epic: [E19 WHOOP connector](README.md) · Status: todo · Depends on: J19.5, J17.4
Read: [install.md](../../install.md), [operations/troubleshooting.md](../../operations/troubleshooting.md)

**Objective:** A self-hoster enables WHOOP from the docs alone and knows the risks of an unofficial source.

## Outputs
- Compose profile `whoop` and the Coolify variant, using the `stable` image with a documented digest-pin alternative.
- `docs/providers/whoop.md`:
  - what syncs and at what grain;
  - the unofficial status and its risks: terms of service, account risk, breakage after WHOOP app updates;
  - MFA and reauth;
  - why the journal stream is off by default;
  - the volume of 6-second HR and its effect on storage.
- Troubleshooting entries: `needs_reauth`, `schema_drift` until a fixed upstream lands, rate limiting.
- [faq.md](../../faq.md) updated. A manual real-account checklist for the owner, as for [Withings](../../providers/withings.md#manual-real-account-checklist).

## Done when
- A clean install with the profile enabled connects a real account by following the docs only.
- The owner's checklist passes: available history and a week of incremental syncs, spot-checked against the WHOOP app.
