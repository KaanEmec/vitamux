# J19.1 Upstream and API verification, ADR, fixtures

Epic: [E19 WHOOP connector](README.md) · Status: in progress · Depends on: J04.1
Read: [connectors#third-party-collectors](../../architecture/connectors.md#third-party-collectors), [metric-catalog](../../architecture/metric-catalog.md), [project#synthetic-fixtures-policy](../../architecture/project.md#synthetic-fixtures-policy)

**Objective:** Replace assumptions about `@dofek/whoop` and WHOOP's private API with verified facts before any code depends on them.

## Outputs
- An ADR adopting `@dofek/whoop`: what it adds over the official WHOOP API, the license of the full dependency tree (including `@dofek/provider-http`, `@dofek/training`, `zod`), the lockstep release pattern, and the conditions under which Vitamux would switch.
- `docs/providers/whoop.md`, in the shape of [providers/withings.md](../../providers/withings.md):
  - **Auth:** the Cognito sign-in with app-based or SMS MFA, token lifetimes, and refresh-token rotation.
  - **Raw access:** whether each method can hand back the response JSON verbatim. The client validates with `zod`, so check that validation does not drop or reshape fields; if it does, the sidecar captures the body through the client's `fetch` or `onRequest` hooks.
  - **Endpoints per stream:** HR and steps (6 s and 300 s step), `getMetricValues`, cycles, sleep, developer workouts and weightlifting, strain deep dive, journal; their history depth, paging and windows.
  - **Content of each record:** what a cycle holds (strain, recovery, HRV, resting HR, SpO2, skin temperature) and what a sleep holds (stages, respiration).
  - **Time:** timestamps, timezone offsets, and cycle boundaries versus local days.
  - **Limits:** 429 with Retry-After, `WHOOP_API_THROTTLE_MS`, safe request rates, account risk.
- A WHOOP ShapeWriter in `tools/fixturegen` that writes synthetic raw payloads per endpoint, including MFA and error responses.
- An owner check with a real account that records only shape fingerprints and field lists, never values.

## Done when
- Every point above is marked confirmed or corrected in `docs/providers/whoop.md`, and the architecture docs are updated where they differ.
- The ADR is accepted.
- Fixtures pass the privacy guard.
