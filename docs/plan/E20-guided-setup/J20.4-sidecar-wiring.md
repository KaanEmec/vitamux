# J20.4 Sidecars wired automatically and detected in the panel

Epic: [E20 Guided source setup in the web panel](README.md) · Status: done (2026-10-04) · Depends on: J20.1, J17.2
Read: [connectors#remote-sidecar-mode](../../architecture/connectors.md#remote-sidecar-mode), [deploy/compose.md](../../deploy/compose.md), [install.md](../../install.md)

**Objective:** Turning on Garmin or WHOOP takes one line or one toggle. Vitamux then finds the sidecar on its own, with no URL or secret to copy.

## Outputs
- **Secrets.** The `init-secrets` setup service also generates one shared secret per bundled sidecar (`garmin`, `whoop`). Compose mounts each secret into both `vitamux` and its sidecar.
- **Registration.** The default `VITAMUX_SIDECARS` lists the bundled sidecars at their service names, so no configuration is needed. A sidecar whose profile is off is reported as `needs_sidecar`, not as an error.
- **Enabling.**
  - Compose: `COMPOSE_PROFILES=garmin,whoop` in `.env`, then `docker compose up -d`.
  - Coolify: verify whether profiles work there. If they don't, ship a per-sidecar toggle another way, such as a replica count variable or a variant file, and document the toggle.
- **Panel.** Garmin and WHOOP are always listed under Connect a source. While their sidecar is unreachable, a card shows:
  - the exact line to add for this install (Compose or Coolify);
  - a **Check again** button;
  - the upstream version and unofficial status once the sidecar is detected.
- **Custom sidecars.** Settings → Sources → **Add a sidecar**:
  - takes a name and a private-network URL;
  - Vitamux generates the shared secret and shows it once, to paste into the sidecar;
  - the secret is stored sealed, removable, and audited.
  - Environment-registered sidecars are shown read-only.

## Done when
- On a fresh Compose install, setting the profile line and running `up` makes Garmin and WHOOP appear as `ready` without touching a secret or URL.
- With the profile off, the panel shows `needs_sidecar` with the right instruction, and nothing is logged as an error.
- A custom sidecar added in the panel passes `describe` and appears under Connect a source.
