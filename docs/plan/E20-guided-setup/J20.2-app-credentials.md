# J20.2 Provider app-credential store and setup API

Epic: [E20 Guided source setup in the web panel](README.md) · Status: todo · Depends on: J20.1, J03.1, J10.4
Read: [ADR-0011](../../adr/0011-secrets-vault.md), [api#conventions](../../architecture/api.md#conventions), [connectors#oauth-connection-flow](../../architecture/connectors.md#oauth-connection-flow)

**Objective:** Provider app credentials live sealed in PostgreSQL, can be changed through the API, and take effect without a restart.

## Outputs
- **Store.** Migration `provider_app_credentials`: provider, client id, sealed secret, `key_id`, `updated_at`, `updated_by`. AAD `provider_app:<provider>`. Included in `vitamux keys rotate`, backup and restore.
- **Resolver.** Connectors ask for app credentials on each authorization, exchange and refresh, instead of receiving them once at start. The environment value comes first, then the database. The Withings connector and its notifications use it; `cmd/vitamux` no longer passes the client secret at start.
- **Endpoints** (owner session; OpenAPI, `authz.yaml` and the API reference updated):
  - `GET /api/v1/providers`: for each registered connector, its setup state, official flag, auth kind, callback URL (`${VITAMUX_PUBLIC_URL}/oauth/<provider>/callback`) and readiness problems (public URL missing, not https, IP host, over 255 characters).
  - `PUT /api/v1/providers/{provider}/app-credentials`: client id and secret, write-only.
  - `DELETE /api/v1/providers/{provider}/app-credentials`: refused while connections use them, unless confirmed.
  - `POST /api/v1/providers/{provider}/app-credentials/verify`: checks the client id and secret against the provider where the provider allows it without a user grant. Otherwise it answers `unverifiable` and the first connect checks them.
- **Audit and redaction.** Audit events `provider_app.set`, `provider_app.delete`, `provider_app.verify`. The redaction audit gains a sentinel Withings secret entered through the API, and expects zero hits in logs, audit and jobs.
- [configuration.md](../../configuration.md): the Withings variables become optional overrides of the panel value.

## Done when
- Setting, replacing and deleting Withings app credentials through the API changes the next OAuth flow without a restart.
- An environment value wins over a stored one and is reported as `managed_by_environment`.
- Key rotation and a backup–restore round trip keep the stored secret usable.
- The redaction audit passes.
