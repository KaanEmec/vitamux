# J20.6 First-run flow, end-to-end tests and install docs

Epic: [E20 Guided source setup in the web panel](README.md) · Status: done (2026-10-04) · Depends on: J20.3, J20.5
Read: [install.md](../../install.md), [frontend#navigation](../../architecture/frontend.md#navigation)

**Objective:** A new owner is led from the first sign-in to a first connected source, and the install guide relies on the panel.

## Outputs
- **First run.** With no connections, Today and Connections show a **Connect a source** card. It lists every provider with its setup state and a single next action.
- **Install docs.**
  - [install.md](../../install.md) step 6 becomes "Connect sources in the panel".
  - The `.env` and secret-file route for Withings moves to an "automated installs" note.
  - A new step covers turning on the Garmin and WHOOP profiles in Compose and Coolify.
  - [troubleshooting](../../operations/troubleshooting.md) gets the setup errors.
- **Smoke test.** A real-stack test goes from a fresh install through Withings (fake provider), Garmin and WHOOP (replay sidecars) to their first syncs, without editing any file except the profile line.

## Done when
- The smoke test passes in CI.
- Someone new to Vitamux connects all three sources from the docs and the panel alone. The run is recorded in the PR with any friction found.
