# Lab analytes

Generated by `go run ./internal/documents/analytes/gen` from [`internal/documents/analytes`](../internal/documents/analytes); do not edit. Rules: [analyte-catalog.md](architecture/analyte-catalog.md). Catalogue version 1.

A conversion turns a printed value into the canonical unit as `value × factor + offset`; only affine conversions have an offset. Refused units measure a different quantity and are never converted. A canonical unit of `-` means values are kept as printed only. Units match ignoring case, spaces and parentheses, with µ/μ/u/mcg for micro and 10⁹, 10^9, x10E9 for powers of ten. Name, code and aliases are the seeded printed labels; owner aliases are added through the API. No LOINC code is filled until it is verified on loinc.org.
