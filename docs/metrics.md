# Metrics and units

Generated by `go run ./internal/catalog/gen` from [`internal/catalog`](../internal/catalog); do not edit. Rules for adding codes and the codes not yet implemented: [metric-catalog.md](architecture/metric-catalog.md). Units are canonical per metric; source units convert through [Units](#units).

Kinds: `sample`, `interval`, `daily_value` (see [data-model](architecture/data-model.md#measurements)). A kind of `-` means the value is derived from sleep sessions, or for a derived code from another metric's series (rule extension E2). Aggregation values are defined in [resolution](architecture/resolution.md#within-source-aggregation). Plausible is the range outside which a value is flagged `implausible`. Apple HK and Withings columns are informational; HK ids omit the `HKQuantityTypeIdentifier` prefix.

## Windows and strategies by aggregation

Bucket size is 5 minutes for `intensive` and `additive`. Provider-scoped scores and selection-only metrics (`resting_heart_rate`, `hrv_rmssd_nightly`, `intensity_light_time`, `intensity_moderate_time`, `intensity_vigorous_time`, `sedentary_time`, `spo2_nightly`, `respiratory_rate_nightly`, `skin_temperature_nightly`, `sleep_temperature_deviation`) lose `mean`, `min` and `max`. Metrics in a group add the `reading` window.

| Aggregation | Windows | Strategies |
| --- | --- | --- |
| intensive | bucket, hour, local_day, local_night, sleep_episode, latest | single_source, first_available, mean, min, max, latest, earliest |
| additive | bucket, hour, local_day | single_source, first_available, mean, min, max, sum, latest, earliest |
| latest | local_day, latest | single_source, first_available, mean, min, max, latest, earliest |
| daily_summary | local_day, latest | single_source, first_available, mean, min, max, latest, earliest |
| sleep_derived | local_night, sleep_episode | single_source, first_available, mean, min, max, latest, earliest, event_priority |

`sum` needs an explicit duplicate-risk acknowledgement in the rule.
