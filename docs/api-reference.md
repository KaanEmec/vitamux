# API reference

Generated by `go run ./tools/apiref` from [`api/openapi.yaml`](../api/openapi.yaml) (the contract: parameters, bodies, responses) and [`api/authz.yaml`](../api/authz.yaml); do not edit. Conventions such as authentication, pagination, errors and idempotency are in [architecture/api.md](architecture/api.md).

Access: `public` needs no credentials (an OAuth state or hook token authorizes it), `session` is the owner's browser session only, `client` is a client or device token for its own connection, and a scope admits the owner's session or an API key with that scope or `admin`. *CSRF*: a session request must send `X-CSRF-Token`. *Planned*: in the spec, not served yet (404).
